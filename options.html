SNATCHER settings

1 · Download clients

Each torrent app you send to — seedbox or local: ruTorrent, Deluge, qBittorrent or Transmission. The address is the one you open its web interface at in the browser, e.g. https://box.example.com:12345 (ruTorrent: plus relative path /rutorrent), http://192.168.1.10:8112 (Deluge), :8080 (qBittorrent) or :9091 (Transmission). Coming from Add Remote Torrent? Export its settings, then use Import from Add Remote Torrent below to bring over your server, password and every download folder.

2 · Destinations (folders)

Where things land. Directory is the path on the client (e.g. /home/user/downloads/movies); leave blank for the client's default. Label is the ruTorrent/Deluge/Transmission label or qBittorrent category. The ● picks the fallback used when no rule matches.

3 · Rules (auto-detect the section)

Checked top to bottom, first match wins. Match is a case-insensitive regex, e.g. movies|films. Row rules look at the torrent's own row (category icon, category link, title); Page rules look at the page title, URL, headings and the highlighted menu item. Row matches always beat page matches. Site limits a rule to a tracker, e.g. *.mytracker.org, or * for all.

4 · Where SNATCHER runs

SNATCHER only runs on a site by itself once you've allowed it. On any other site, click its toolbar icon (or Alt+Shift+S) to use it there once; the panel then offers Always run here. On allowed sites, clicking a torrent link goes straight to SNATCHER.
