SNATCHER settings

1 · Download clients

Each ruTorrent you send to — seedbox or local. The URL is the address you open ruTorrent at in the browser, e.g. https://box.example.com:12345 plus relative path /rutorrent. Easiest: in Add Remote Torrent export its settings, then use Import from Add Remote Torrent below. That brings over your server, password and every download folder.

2 · Destinations (folders)

Where things land. Directory is the path on the client (e.g. /home/user/downloads/movies); leave blank for ruTorrent's default. Label is the ruTorrent label. The ● picks the fallback used when no rule matches.

3 · Rules (auto-detect the section)

Checked top to bottom, first match wins. Match is a case-insensitive regex, e.g. movies|films. Row rules look at the torrent's own row (category icon, category link, title); Page rules look at the page title, URL, headings and the highlighted menu item. Row matches always beat page matches. Site limits a rule to a tracker, e.g. *.mytracker.org, or * for all.
